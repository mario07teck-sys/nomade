# Nomade

Nomade transfère les données d'un téléphone Android vers un autre, en passant par le PC : photos, vidéos, contacts, SMS, journal d'appels, applications et texte des notes.

**Télécharger** : prenez `Nomade-Setup-x.y.z.exe` dans la dernière version publiée, à droite (« Releases »). Nomade se met ensuite à jour tout seul.

- Installation dans votre dossier personnel, sans droits administrateur.
- Rien n'est jamais effacé sur le téléphone.
- Un téléphone verrouillé ou éteint n'est pas pris en charge.

Ce dépôt ne contient que les installateurs et les notes de version.
